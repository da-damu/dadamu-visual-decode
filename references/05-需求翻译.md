# 需求翻译

这份文件解决的是最后一公里：你已经知道喜欢什么，也知道术语，但怎么让 AI、设计师、剪辑师做出来。

---

## 一、为什么形容词没用

「高级」「大气」「有质感」不是需求，是判断。

- 它们没有指向任何可执行的动作
- 不同的人对同一个词有不同画面
- AI 会回到训练数据里最平均的那个版本
- 结果不对时，你不知道该改哪一项

**可执行的需求 = 可观察的特征 + 参数 + 禁止项 + 验收标准。**

---

## 二、翻译公式

```
载体 + 目标 + 参考 + 必须保留 + 可以变化 + 禁止 + 参数 + 验收
```

| 部分 | 回答什么 | 例子 |
| --- | --- | --- |
| 载体 | 做成什么 | 9:16 竖屏短视频，30 秒 |
| 目标 | 让谁产生什么感受 / 做什么 | 让观众觉得这家咖啡馆安静、贵、不吵 |
| 参考 | 具体参考哪一段 / 哪个元素 | 参考 A 的 00:08–00:15 的光影和节奏，不参考字幕 |
| 必须保留 | 哪些不能动 | 低饱和暖调、人物占 1/3、硬切为主 |
| 可以变化 | 哪些交给对方 | 景别、机位、BGM |
| 禁止 | 哪些绝对不要 | 高饱和霓虹、快节奏卡点、大面积花字 |
| 参数 | 具体设置 | 35mm，f/2，1/50s，24fps，饱和 -20% |
| 验收 | 怎么判断做对了 | 静音看是否安静；背景文字是否不可读；是否没有花哨转场 |

## 四、三版需求卡

### 版本 A · 对 AI

写给生图 / 生视频 / 生成 UI 的模型。结构化、参数化、禁止项写死。

```markdown
【载体】9:16 竖屏短视频，30 秒，1080×1920，24fps
【目标】安静、贵、不吵的咖啡馆
【主体】一位 30 岁左右的女性坐在窗边，侧脸，手里拿杯子
【参考】<作品 A> 的 00:08–00:15：低饱和暖调、浅景深、背景霓虹虚化
【必须保留】
- 低饱和暖调，黑位略提，不要纯黑
- 人物占画面 1/3，背景虚化到只剩色块
- 硬切为主，不要花哨转场
【可以变化】
- 景别、机位、背景音乐
【禁止】
- 高饱和霓虹
- 快节奏卡点
- 大面积花字
- 蓝紫渐变
- 塑料皮肤
【参数】
- 35mm，f/2，1/50s，ISO 400
- 色温 3800K，饱和 -20%，高光 +10，阴影 +5
- 颗粒 5%
【输出】
- 1080×1920，H.264，12–20 Mbps
```

**对 AI 的额外规则：**

- 参考要具体到时间段 / 元素，不要只给整条片子
- 禁止项要写，模型会默认加东西
- 参数给范围，不要只给一个数
- 一次只改一个变量，方便定位问题

### 版本 B · 对设计师 / 剪辑师

写给人看。少一点参数，多一点意图、优先级和参考。

```markdown
这次要做一条 30 秒的竖屏短片，给一家咖啡馆。

我想要的感觉：安静、贵、不吵。不是那种网红打卡的热闹，是下午三点没什么人、光从窗户进来、杯子放桌上有一点点声音的那种。

参考：<作品 A> 的 00:08–00:15。只要它的光影和节奏，不要它的日文字幕和滤镜。

必须保留：
1. 低饱和暖调，暗部不要死黑
2. 人物占画面三分之一，背景虚化
3. 硬切为主，不要花哨转场
4. 环境声铺底，人声清楚

可以变化：景别、机位、BGM，你按素材判断。

不要：
- 高饱和霓虹
- 快节奏卡点
- 大面积花字
- 蓝紫渐变

验收：
1. 静音看一遍，是否安静？
2. 背景招牌文字是否不可读？
3. 全片是否没有花哨转场？
4. 手机外放人声是否清楚？
```

### 版本 C · 对自己

拍完 / 剪完 / 做完，逐条打勾。

```markdown
- [ ] 整体是不是低饱和暖调？
- [ ] 黑位有没有死黑？
- [ ] 人物是不是占 1/3 左右？
- [ ] 背景是不是虚化到只剩色块？
- [ ] 有没有出现高饱和霓虹？
- [ ] 有没有花哨转场？
- [ ] 有没有大面积花字？
- [ ] 环境声有没有铺底？
- [ ] 人声在手机外放清楚吗？
- [ ] 静音看一遍，是否安静？
```

## 五、句式库

### 视频

**景别 / 机位：**

- 「人物占画面三分之一，头顶留一点空间，不要切到手指。」
- 「低机位，略仰拍，让人显得有力量。」
- 「正面平视，中心构图，背景干净。」

**运镜：**

- 「镜头缓慢推近，2 秒推进约 10%，速度均匀。」
- 「跟着人物走，保持他在画面同一位置，背景流动。」
- 「固定机位，不要晃，让主体自己动。」

**光线：**

- 「侧逆光，人物边缘有一圈轮廓光，背景压暗。」
- 「窗光从左侧来，右侧用反光板补一点，光比不要太大。」
- 「硬光，阴影边缘清楚，不要柔光箱。」

**调色：**

- 「整体降饱和 20%，高光偏暖 300K，阴影偏青 5。」
- 「黑位提到 +10，不要纯黑；高光不要溢出。」
- 「青橙，但肤色要自然，不要变成橘色。」

**剪辑：**

- 「前 3 秒 6 个快切，之后每 2–3 秒一刀。」
- 「全片硬切，不要叠化。」
- 「转场用物体遮挡，不要用插件转场。」

**声音：**

- 「环境声铺底 -30 LUFS，人声 -16 LUFS，BGM -28 LUFS。」
- 「转场处加 whoosh，不要每个切点都加。」
- 「最后 1 秒静音，留一个停顿。」

### 网页 / App

**布局：**

- 「12 栏网格，容器 1200px，左右 24px 边距，区块间距 96px。」
- 「首屏左边标题和按钮，右边产品截图，比例 5:7。」
- 「移动端变单栏，卡片间距 16px。」

**字体：**

- 「标题 56px / 1.1，正文 18px / 1.6，注释 14px / 1.5。」
- 「标题用衬线，正文用无衬线，最多两种字体。」
- 「大标题字距 -0.02em，正文 0。」

**色彩：**

- 「主色一个，辅助色一个，中性色 6 档。」
- 「背景 #F7F7F5，卡片 #FFFFFF，文字 #111111。」
- 「强调色只用在主按钮和链接，面积不超过 10%。」

**组件：**

- 「按钮高 44px，圆角 10px，主按钮实心，次按钮描边。」
- 「卡片圆角 16px，内边距 24px，阴影 0 8px 24px rgba(0,0,0,.08)。」
- 「输入框要有 default / focus / error / disabled 四种状态。」

**动效：**

- 「进入 300ms ease-out，从下方 16px 淡入。」
- 「列表错峰 40ms，不要超过 300ms。」
- 「hover 阴影加深、上移 2px，150ms。」
- 「支持 prefers-reduced-motion。」

### 图片

**构图：**

- 「三分法，人物在右侧 1/3 线，左侧留白放标题。」
- 「低角度，广角 24mm，前景有虚化的杯子。」
- 「中心对称，背景干净，主体占 1/2。」

**光线：**

- 「侧逆光，暖色，背景压暗，人物边缘有一圈光。」
- 「窗光从左来，柔光，光比 1:2。」
- 「硬光，阴影清楚，对比强。」

**色彩：**

- 「低饱和暖调，黑位 +10，高光偏暖，阴影偏青。」
- 「莫兰迪色，每个颜色加灰，饱和 -30%。」
- 「青橙，但肤色自然。」

**质感：**

- 「胶片颗粒 10%，轻微光晕，暗角 -15。」
- 「金属反射，环境光要匹配。」
- 「纸张纹理，半调网点，套色偏移 2px。」

## 六、验收标准

「像不像」不是验收标准。它是主观的，而且改一次就要重新吵一次。

**好的验收标准：**

- 可观察：能用眼睛 / 耳朵判断
- 二元：是 / 否，不是 1–10 分
- 3–5 条：不要太多
- 和需求一一对应：每条都能追溯到「必须保留」或「禁止」

**例子：**

| 需求 | 验收 |
| --- | --- |
| 安静 | 静音看一遍，是否没有紧张感？ |
| 背景虚化 | 背景招牌文字是否不可读？ |
| 硬切为主 | 全片是否没有花哨转场？ |
| 人声清楚 | 手机外放是否能听清每个字？ |
| 低饱和 | 画面里是否有超过 3 个高饱和色块？ |
| 高级 | 颜色是否不超过 3 个？字体是否不超过 2 种？留白是否够？ |

## 七、结果不对时怎么改

先判断是哪一维不对，再改一个变量。不要一次改五个。

| 问题 | 可能的原因 | 先改什么 |
| --- | --- | --- |
| 结构不对 | 构图 / 布局 / 镜头顺序 | 改构图、景别、网格、信息层级 |
| 气质不对 | 光 / 色 / 材质 | 改色温、饱和、对比、光比、材质 |
| 节奏不对 | 剪辑 / 动效 / 音乐 | 改镜长、切点、缓动、BPM |
| 重点不对 | 景别 / 字号 / 对比 / 位置 | 改主体大小、字号层级、颜色对比 |
| 太假 | 磨皮 / 光 / 纹理 / 反射 | 加颗粒、保留皮肤纹理、统一光向 |
| 太满 | 元素多 / 留白少 | 删元素、加留白、减颜色 |
| 太素 | 对比弱 / 缺重点 | 加一个强调色、加大字号差、加材质 |
| 太吵 | 颜色多 / 动效多 / 音效多 | 减颜色、减动效、减音效 |

**每次只改一个变量，改完再看。** 一次改五个，你不知道是哪一个起了作用。

## 九、常见错误

1. **只给形容词，不给参数。** 「要高级」→ 改成「低饱和、留白、2–3 色、1–2 种字重」。
2. **参考给整条片子。** 改成「参考 00:08–00:15 的光影和节奏，不参考字幕」。
3. **不写禁止项。** AI 会默认加高饱和、花字、渐变、塑料皮肤。
4. **验收写「好看」。** 改成 3–5 条二元检查。
5. **一次改五个变量。** 改成一次一个，改完再看。
6. **把风格当内容。** 「赛博朋克」不能替代「讲什么故事」。
7. **把参考当复制。** 参考是坐标，不是模板。说清楚「参考哪一部分」。
8. **忽略平台。** 9:16 的安全区、压缩、字幕位置，和 16:9 不一样。
9. **忽略成本。** 电影感需要镜头、灯光、调色；手机可以做近似，但不要承诺一模一样。
10. **不给优先级。** 必须保留和可以变化要分开，否则对方不知道哪里能妥协。
