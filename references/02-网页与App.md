# 网页与 App 设计术语表

用法：先看截图 / 页面，找到现象，再查名字。参数是常见起点，不是唯一解。网页能看源码时，以计算样式为准；App 只能看截图时，标清楚「推测」。

---

## 一、布局与网格

| 术语 | 你在页面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 栅格系统 Grid System | 内容对齐到看不见的列 | 秩序、响应式 | 12 栏最常见；桌面 1200–1440px 容器，24px 槽宽 | 8 栏 / 16 栏也有人用 |
| 12 栏网格 12-Column Grid | 页面被分成 12 等份 | 灵活组合 1/2、1/3、1/4 | `grid-template-columns: repeat(12, 1fr)` | 栏目多不等于复杂 |
| 8pt 网格 8-Point Grid | 所有间距是 8 的倍数 | 统一节奏 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 | 小图标可用 4pt 半格 |
| 基线网格 Baseline Grid | 文字底部对齐到同一条线 | 排版稳定 | 行高 8 或 4 的倍数 | 中文行高常比英文大 |
| 间距系统 Spacing Scale | 间距只有几档，不随便写 | 一致、可维护 | 4, 8, 12, 16, 24, 32, 48, 64 | 不要把 13px、17px 混进去 |
| 容器 Container | 内容有最大宽度，两侧留白 | 阅读舒适、适配大屏 | `max-width: 1200px; margin: 0 auto; padding: 0 24px` | 全屏背景可以突破容器 |
| 最大宽度 Max-Width | 文字不会一行拉太长 | 可读性 | 正文 60–75 字符；中文 35–45 字 | 和容器宽度不是一回事 |
| 断点 Breakpoint | 屏幕宽度到某个值时布局变化 | 响应式 | 640 / 768 / 1024 / 1280 / 1536 | 按内容断，不按设备断 |
| 响应式 Responsive | 同一页面在手机 / 平板 / 桌面都可用 | 适配 | 流式网格 + 断点 + 弹性图片 | 和自适应不同 |
| 自适应 Adaptive | 为不同设备做几套固定布局 | 精确控制 | 多套模板 / 独立页面 | 维护成本高 |
| 流式布局 Fluid | 宽度按比例伸缩 | 连续适配 | `%` / `fr` / `clamp()` | 太宽时文字会难读 |
| 固定布局 Fixed | 宽度固定，不随屏幕变 | 海报式、展示页 | `width: 1200px` | 手机上会横向滚动 |
| 卡片布局 Card Layout | 内容装进一张张卡片 | 模块化、可扫描 | 圆角 12–16px，内边距 16–24px，阴影 | 卡片太多会碎 |
| 瀑布流 Masonry | 卡片高低不一，错落排列 | 图片、灵感、商品 | CSS columns / JS 布局 | 阅读顺序不固定 |
| 杂志式排版 Editorial | 大标题、分栏、图文混排 | 品牌、内容、叙事 | 12 栏 + 大字号 + 不对称 | 信息密度要控制 |
| 英雄区 Hero | 首屏最大的一块 | 定调、主 CTA | 大标题 + 副标题 + 按钮 + 图 / 视频 | 不要塞太多信息 |
| 首屏 Above the Fold | 不滚动就能看到的部分 | 第一印象、转化 | 桌面 1440×900 内；手机 390×844 内 | 重要信息别放折叠线以下 |
| 留白 White Space | 元素之间大量空白 | 呼吸、聚焦、高级 | 区块间距 64–120px | 留白不是空，要有比例 |
| 视觉层级 Visual Hierarchy | 第一眼、第二眼、第三眼有顺序 | 引导阅读 | 字号、颜色、间距、位置、对比 | 层级太多等于没有层级 |
| 对齐 Alignment | 元素边缘在同一条线上 | 秩序 | 左对齐最常见；数字右对齐 | 混用对齐会乱 |
| 亲密性 Proximity | 相关元素靠得近 | 分组 | 组内 8–16px，组间 32–64px | 比加分割线更有效 |
| 重复 Repetition | 同样的样式反复出现 | 统一、品牌 | 同一种按钮 / 卡片 / 标题 | 重复不等于复制粘贴 |
| 对比 Contrast | 大小、颜色、粗细差异明显 | 强调、可读 | 标题 / 正文至少 2 倍字号差 | 对比不足会平 |
| F 型阅读 F-Pattern | 用户先横看，再竖扫 | 内容页、列表 | 标题和首行放关键词 | 不是所有页面都 F 型 |
| Z 型阅读 Z-Pattern | 视线走 Z 字 | 落地页、广告 | 左上 → 右上 → 左下 → 右下 | 适合信息少的页面 |
| 折叠线 Fold | 首屏底部的位置 | 转化、内容分层 | 桌面 900px 左右；手机 844px | 不是绝对线 |
| Bento 布局 Bento Grid | 大小不一的圆角格子拼在一起 | 产品卖点、功能展示 | 12 栏网格 + 不同跨度 + 16–24px 间距 | 格子大小要有节奏 |
| 分栏 Columns | 内容分成 2–3 列 | 长文、杂志、对比 | 2 栏 16–24px 槽宽；3 栏更宽 | 手机上要变单栏 |
| 全屏分段 Full-Screen Sections | 每一屏一个主题 | 品牌故事、产品发布 | 100vh 一段 + 滚动吸附 | 内容少时容易空 |

## 二、间距与尺寸

| 术语 | 你在页面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 内边距 Padding | 内容到容器边缘的距离 | 呼吸、可点击区域 | 卡片 16–24px；按钮 12–16px 上下，20–24px 左右 | 和 margin 不同 |
| 外边距 Margin | 元素与元素之间的距离 | 分组、节奏 | 组内 8–16px；组间 32–64px | 不要用 margin 做布局 |
| 间距阶 Spacing Step | 间距只有几档 | 统一 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 | 超过 7 档就难维护 |
| 圆角 Border Radius | 卡片 / 按钮角是圆的 | 亲和、现代、品牌 | 4px 小，8–12px 中，16–24px 大，999px 胶囊 | 圆角要统一 |
| 边框 Border | 元素外有一圈线 | 分隔、强调 | 1px solid #E5E7EB | 和阴影一起用要克制 |
| 阴影 Shadow | 元素浮起来 | 层级、卡片 | `0 1px 2px rgba(0,0,0,.05)`, `0 8px 24px rgba(0,0,0,.08)` | 阴影方向要一致 |
| 悬浮 Elevation | 阴影越大，层级越高 | 模态、菜单、卡片 | 1–5 级，不要超过 5 种 | Material 的 elevation 概念 |
| 点击区域 Touch Target | 按钮 / 图标可点的范围 | 可用性 | iOS 44×44pt，Android 48×48dp | 视觉小可以，热区不能小 |
| 安全区 Safe Area | 内容避开刘海 / 底部手势条 | 手机适配 | `env(safe-area-inset-*)` | 竖屏视频也要留 |
| 最大内容宽度 Measure | 一行文字的长度 | 可读性 | 45–75 字符；中文 35–45 字 | 太宽会串行 |

## 三、字体排印

| 术语 | 你在页面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 字体家族 Typeface | 字的整体风格 | 品牌、气质 | 无衬线现代；衬线文艺；等宽技术 | 一个页面 1–2 种就够 |
| 衬线 Serif | 笔画末端有小装饰 | 传统、可信、编辑感 | Georgia / 思源宋体 / Noto Serif | 小字号屏幕上易糊 |
| 无衬线 Sans-Serif | 笔画末端干净 | 现代、清晰、UI 默认 | Inter / SF / 思源黑体 | 最常见 |
| 等宽 Monospace | 每个字宽度一样 | 代码、数据、技术感 | JetBrains Mono / SF Mono | 正文不要用 |
| 手写 Script | 像手写 | 个性、亲切、婚礼 | 手写字体 / 书法 | 可读性差，少用 |
| 字重 Weight | 粗体 / 细体 | 层级、强调 | 正文 400，标题 600–700，轻标题 300 | 不要用太多档 |
| 字号 Size | 字的大小 | 层级、可读 | 正文 16–18px；移动端 16px 起 | 小于 14px 要谨慎 |
| 行高 Line-Height | 行与行的距离 | 可读、呼吸 | 正文 1.5–1.7；标题 1.1–1.3 | 中文需要更大行高 |
| 字距 Letter-Spacing | 字与字的距离 | 大标题收紧、正文正常 | 大标题 -0.02em；正文 0；全大写 +0.05em | 中文不要乱加 |
| 词距 Word-Spacing | 英文单词间距 | 可读 | 默认即可 | 中文不适用 |
| 行宽 Measure | 一行多少字 | 可读性 | 45–75 字符；中文 35–45 字 | 和容器宽度不同 |
| 字号阶 Type Scale | 字号成比例 | 层级、节奏 | 1.25 倍（16, 20, 25, 31, 39）或 1.333 倍 | 不要随便写 17 / 19 / 23 |
| 模块化比例 Modular Scale | 用固定比例生成字号 | 系统化 | 1.125 / 1.25 / 1.333 / 1.5 | 比例越大，层级越强 |
| 可变字体 Variable Font | 一个字重连续变化 | 性能、精细 | `font-variation-settings` | 兼容性要查 |
| 字体配对 Font Pairing | 标题和正文用两种字 | 对比、气质 | 衬线标题 + 无衬线正文；或同族不同字重 | 不要超过 2 种 |
| 中英混排 CJK + Latin | 中文和英文混在一起 | 国际化、品牌 | 中文用思源黑体，英文用 Inter；注意基线 | 英文不要用中文字体 |
| 标点挤压 Punctuation Compression | 中文标点占位更紧 | 排版精细 | CSS `text-spacing` / 手动 | 浏览器支持有限 |
| 避头尾 Kinsoku | 标点不在行首 / 行尾 | 中文排版 | CSS `line-break: strict` | 需要测试 |
| 展示字体 Display | 很大、很有个性的标题字 | 品牌、海报 | 大字号 + 紧字距 | 正文不要用 |
| 正文字体 Body | 长文阅读用的字 | 可读 | 16–18px，行高 1.6 | 不要用展示字体 |
| 说明文字 Caption | 小字注释 | 补充信息 | 12–14px，颜色弱化 | 对比度要够 |
| 数字等宽 Tabular Figures | 数字宽度一致 | 表格、价格 | `font-variant-numeric: tabular-nums` | 价格对齐很重要 |
| 字体许可 Font License | 能不能商用 | 法律 | 查 OFL / 商业授权 | 不要随便用系统字体做 logo |

## 四、色彩系统

| 术语 | 你在页面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 主色 Primary | 品牌最常出现的颜色 | 识别、行动 | 1 个；按钮 / 链接 / 高亮 | 不要到处都是 |
| 辅助色 Secondary | 补充主色的颜色 | 层次、区分 | 1–2 个；标签 / 图表 | 不要和主色打架 |
| 强调色 Accent | 少量高饱和的点缀 | 吸引注意 | 1 个；CTA / 提示 | 用量 5–10% |
| 中性色 Neutral | 黑、白、灰、米 | 背景、文字、边框 | 6–9 档灰阶 | 不要用纯黑纯白打底 |
| 语义色 Semantic | 成功、警告、错误、信息 | 状态 | 绿 / 黄 / 红 / 蓝 | 不要只靠颜色 |
| 色板 Palette | 一组固定颜色 | 统一 | 5–9 个主色 + 中性色 | 颜色越多越难统一 |
| 色阶 Shades / Tints | 同一颜色的深浅 | 状态、层次 | 50–900 或 100–900 | 不要手动调，生成色阶 |
| 对比度 Contrast Ratio | 文字和背景的亮度差 | 可读、无障碍 | 正文 4.5:1；大字 3:1；UI 3:1 | 用工具测，不靠眼看 |
| WCAG AA / AAA | 无障碍标准 | 合规 | AA 4.5:1，AAA 7:1 | 品牌色常不达标 |
| 暗色模式 Dark Mode | 深色背景、浅色文字 | 夜间、省电、酷 | 背景 #0F1115–#1A1D23；文字 #E5E7EB | 不要直接反色 |
| 设计变量 Design Tokens | 颜色 / 间距 / 字体写成变量 | 可维护、换肤 | `--color-primary`, `--space-4` | 和组件库配合 |
| 渐变 Gradient | 两个以上颜色过渡 | 氛围、科技、品牌 | 线性 / 径向 / 锥形 | 不要过度 |
| 弥散渐变 Mesh Gradient | 多个色块柔和融合 | 现代、梦幻、AI 感 | 多个径向渐变叠加 + 模糊 | 容易过时 |
| 双色调 Duotone | 两个颜色映射明暗 | 海报、品牌、复古 | 渐变映射 | 和滤镜不同 |
| 单色系 Monochromatic | 一个色相的不同明度 | 统一、极简 | 同一 H，变 S / L | 容易单调 |
| 邻近色 Analogous | 色轮相邻的 2–3 色 | 和谐 | 蓝 / 青 / 绿 | 对比弱 |
| 互补色 Complementary | 色轮对面 | 张力、强调 | 蓝 / 橙，紫 / 黄 | 用量要控制 |
| 品牌色 Brand Color | 品牌识别色 | 记忆、统一 | 1 个主色 + 1 个辅助 | 不要每页都换 |
| 表面色 Surface | 卡片 / 弹层的背景 | 层级 | 比页面背景亮或暗 1 档 | 不要和背景同色 |
| 边框色 Border | 分隔线 / 输入框边 | 结构 | 比背景深 1–2 档 | 不要太黑 |
| 文本色 Text Primary / Secondary / Disabled | 不同重要度的文字 | 层级 | 主 90%，次 60%，禁用 38% | 对比度要够 |
| 透明度 Opacity | 元素半透明 | 层次、叠加 | 0.04–0.12 常用于背景 | 不要用透明度代替颜色 |
| 混合模式 Blend Mode | 图层叠加方式 | 光效、纹理 | multiply / screen / overlay | 注意可读性 |
| 玻璃效果 Glassmorphism | 半透明 + 模糊 + 细边 | 现代、层次 | `backdrop-filter: blur(20px)` + 白 10% + 1px 白 20% | 性能开销 |
| 噪点 Noise | 背景有细颗粒 | 质感、去塑料感 | SVG 噪点 / 图片叠加 3–8% | 不要太多 |

## 五、组件与控件

| 术语 | 你在页面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 主按钮 Primary Button | 最显眼的按钮 | 主行动 | 实心主色，圆角 8–12px，高 40–48px | 一屏一个主按钮 |
| 次按钮 Secondary Button | 描边或浅底按钮 | 次要行动 | 1px 边框 / 浅色底 | 和主按钮拉开层级 |
| 幽灵按钮 Ghost Button | 只有文字 / 透明底 | 弱行动 | 透明底 + 文字色 | 不要用在关键转化 |
| 文字按钮 Text Button | 看起来像链接 | 轻量行动 | 主色文字 + 下划线 / hover | 点击区域要够 |
| 输入框 Input | 用户输入文字的地方 | 表单 | 高 40–48px，圆角 8px，边框 1px | 要有 focus / error 状态 |
| 选择器 Select | 下拉选一个 | 选项多时 | 高 40–48px，箭头图标 | 选项少用单选 |
| 开关 Switch | 左右拨动 | 开关设置 | 44×24px，滑块 20px | 要有明确标签 |
| 复选框 Checkbox | 方框打勾 | 多选 | 18–20px，圆角 4px | 和开关不同 |
| 单选框 Radio | 圆圈选一个 | 单选 | 18–20px | 选项少时用 |
| 滑块 Slider | 拖动选数值 | 范围 | 轨道 4px，滑块 16–20px | 要有当前值 |
| 标签页 Tabs | 顶部几个标签切换 | 内容分组 | 下划线 / 胶囊；高 40–48px | 标签 2–6 个 |
| 面包屑 Breadcrumb | 显示层级路径 | 导航 | 小字 + 分隔符 | 移动端可省略 |
| 分页 Pagination | 页码 | 长列表 | 32–40px 按钮 | 无限滚动可替代 |
| 卡片 Card | 一块圆角内容 | 分组、商品、文章 | 圆角 12–16px，内边距 16–24px，阴影 | 卡片里不要再套卡片 |
| 列表 List | 一行一行信息 | 扫描、设置 | 行高 56–72px，分隔线 1px | 和表格不同 |
| 表格 Table | 多列数据 | 对比、管理 | 表头 12–14px，行高 48–56px | 移动端要横向滚动或卡片化 |
| 模态框 Modal | 中间弹出的层 | 聚焦、确认 | 遮罩 40–60% 黑，卡片 480–640px 宽 | 不要套模态 |
| 抽屉 Drawer | 从侧边滑出 | 导航、详情 | 宽 320–480px，遮罩 | 移动端常用底部抽屉 |
| 弹出层 Popover | 点按钮弹出的小层 | 菜单、说明 | 8–12px 圆角，阴影 | 注意点击外部关闭 |
| 提示 Tooltip | 悬停出现的小字 | 解释图标 | 深色底 + 白字，6–8px 圆角 | 移动端少用 |
| 通知 Toast | 顶部 / 底部短暂提示 | 反馈 | 2–4 秒自动消失 | 不要放重要信息 |
| 徽标 Badge | 小红点 / 数字 | 提醒 | 16–20px 圆点 | 数字超过 99 显示 99+ |
| 头像 Avatar | 用户 / 品牌图 | 识别 | 32–48px 圆形 / 圆角 | 要有 fallback |
| 缩略图 Thumbnail | 小图 | 预览 | 16:9 / 1:1，圆角 8px | 和主图不同 |
| 骨架屏 Skeleton | 灰色占位块 | 加载 | 和真实布局同尺寸， shimmer 1.2–1.8s | 不要一直闪 |
| 空状态 Empty State | 没内容时的提示 | 引导 | 图标 + 一句话 + 按钮 | 不要只写「暂无数据」 |
| 加载态 Loading | 转圈 / 进度条 | 等待 | 200ms 内不显示，避免闪烁 | 超过 1 秒才需要 |
| 错误态 Error | 红色提示 / 图标 | 纠错 | 红色 + 具体原因 + 解决动作 | 不要只写「出错了」 |
| 悬浮按钮 FAB | 右下角圆形按钮 | 主行动 | 56px 圆形，阴影 | 一屏一个 |
| 底部导航 Tab Bar | 手机底部几个图标 | 主导航 | 3–5 个，49–56px 高 | 不要超过 5 个 |
| 侧边栏 Sidebar | 左侧导航 | 桌面后台 | 240–280px 宽 | 可折叠 |
| 顶部导航 Top Nav | 页面顶部菜单 | 网站导航 | 64–80px 高 | 移动端变汉堡 |
| 搜索栏 Search Bar | 输入关键词 | 查找 | 高 40–48px，放大镜图标 | 要有清除按钮 |
| 筛选器 Filter | 条件筛选 | 缩小范围 | 标签 / 下拉 / 滑块 | 显示已选条件 |
| 标签 Tag / Chip | 小圆角标签 | 分类、筛选 | 高 24–32px，圆角 999px | 可删除要有 × |
| 进度条 Progress | 进度 | 等待、步骤 | 4–8px 高，圆角 | 要有百分比 |
| 步骤条 Stepper | 1-2-3 步骤 | 流程 | 圆圈 + 连接线 | 当前步骤要明显 |
| 轮播 Carousel | 左右滑的图 | 展示、推荐 | 1–5 张，圆点指示 | 自动播放要可暂停 |
| 手风琴 Accordion | 点开收起 | FAQ、分组 | 标题 + 箭头 + 内容 | 一次开一个或多个 |

## 十三、常见组合配方

### 1. 极简 SaaS 落地页

- 白底 / 浅灰底，1 个主色
- 12 栏网格，容器 1200px，区块间距 96–120px
- 大标题 56–72px，正文 18px，行高 1.6
- 圆角 12px，阴影 1 级
- 首屏：标题 + 副标题 + 主按钮 + 产品截图
- 动效：淡入 + 轻微上移，300ms ease-out

### 2. 暗色科技产品页

- 背景 #0B1020，卡片 #141A2A
- 主色青 / 蓝，强调色少量紫
- 1px 边框 + 微弱发光
- 等距插画 / 3D 产品图
- 网格背景 + 粒子
- 动效：滚动触发 + 视差 + 数字滚动

### 3. 编辑式媒体首页

- 白底，黑色衬线大标题
- 12 栏，图文混排，不对称
- 大图 + 小图 + 摘要
- 细分隔线
- 字号层级 4–5 级
- 动效：图片淡入 + 轻微缩放

### 4. 小红书风格封面

- 3:4 竖版，1080×1440
- 大标题 80–120px，2–6 字一行
- 高饱和 / 对比色，粗字
- 人物 / 产品占一半以上
- 贴纸 / 箭头 / 手绘元素
- 文字安全区：上下各留 10–15%

### 5. 微信小程序首页

- 750rpx 设计宽度
- 顶部导航 + 搜索 + 卡片列表
- 圆角 16rpx，间距 24rpx
- 主色 1 个，语义色 4 个
- 底部 tabBar 3–5 个
- 注意胶囊按钮和安全区

### 6. 作品集 / 个人品牌

- 大留白，1–2 种字体
- 大图 + 项目名 + 一句话
- 网格 2–3 列，悬停放大
- 页面转场淡入 / 滑动
- 低饱和，统一色调
- 不要堆技能条
