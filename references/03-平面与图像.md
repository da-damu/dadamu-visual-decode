# 平面与图像术语表

用法：先眯眼看整体，再分区看细节。参数是常见起点，不是唯一解。图像被压缩后，精确色值和字体名往往不可靠，标清楚置信度。

---

## 一、构图

| 术语 | 你在画面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 三分法 Rule of Thirds | 主体在 1/3 线或交叉点 | 平衡、自然 | 画面横竖各分三份 | 不是所有图都适合 |
| 中心构图 Central Composition | 主体在正中间 | 稳定、正式、压迫 | 主体居中，背景对称 | 容易呆板 |
| 对称构图 Symmetry | 左右 / 上下镜像 | 秩序、仪式 | 机位在对称轴，广角正对 | 人拍很难完全对称 |
| 对角线 Diagonal | 主体或线条从一角到另一角 | 动感、纵深 | 道路、栏杆、楼梯 | 不要把画面切死 |
| 引导线 Leading Lines | 线条把视线引向主体 | 纵深、方向 | 道路、走廊、光束 | 线条太强会抢主体 |
| 框架构图 Frame in Frame | 门、窗、树枝框住主体 | 聚焦、窥视 | 前景框架虚化 | 框太满会压抑 |
| 负空间 Negative Space | 主体周围大片空 | 孤独、呼吸、高级 | 主体占 1/5–1/3 | 空不等于白 |
| 前景 / 中景 / 背景 | 画面有前后层次 | 空间感 | 前景虚化树叶 / 肩膀 | 前景太抢会干扰 |
| 视觉重心 Visual Weight | 某一边更重 | 平衡、张力 | 大、暗、饱和、人脸、文字 | 不平衡不一定是错 |
| 平衡 Balance | 两边视觉重量接近 | 稳定 | 大主体配小文字，暗块配亮块 | 对称是平衡的一种 |
| 节奏 Rhythm | 元素重复但有变化 | 动感、秩序 | 重复的窗、柱子、条纹 | 完全重复会死板 |
| 重复 Repetition | 同样的形状 / 颜色反复 | 统一、图案 | 网格、阵列、纹理 | 和节奏不同：节奏有变化 |
| 对比 Contrast | 大小、明暗、冷暖、虚实差异 | 强调 | 大 / 小，黑 / 白，冷 / 暖 | 对比太多会乱 |
| 留白 White Space | 元素之外的空白 | 呼吸、聚焦 | 主体周围 30–60% 空白 | 留白不是浪费 |
| 裁切 Crop | 去掉多余部分 | 聚焦、改变比例 | 裁到主体占 1/2–2/3 | 不要切掉手指 / 头顶 |
| 视角 Angle | 平视 / 俯视 / 仰视 | 权力、情绪 | 平视自然，俯拍弱，仰拍强 | 和焦距一起变 |
| 比例 Scale | 人和物的大小对比 | 规模、渺小 / 巨大 | 广角靠近小物，长焦压缩 | 需要参照物 |
| 黄金分割 Golden Ratio | 主体在 0.618 位置 | 和谐 | 近似三分法 | 不要迷信 |
| 三角构图 Triangle | 三个视觉点形成三角 | 稳定、引导 | 人物 / 产品 / 文字成三角 | 和三分法不同 |
| S 型构图 S-Curve | 河流、道路、身体形成 S | 优雅、纵深 | 曲线引导视线 | 需要自然曲线 |
| 水平线 Horizontal | 地平线 / 海面 / 桌面 | 平静、广阔 | 地平线放 1/3 或 1/2 | 歪了会不舒服 |
| 垂直线 Vertical | 树、柱子、建筑 | 力量、秩序 | 垂直线对齐 | 注意透视变形 |
| 放射线 Radial | 线条从中心向外 | 聚焦、爆发 | 阳光、隧道、放射图案 | 中心要明确 |
| 图案 Pattern | 重复的图形 | 节奏、装饰 | 网格、条纹、圆点 | 和纹理接近 |
| 极简 Minimal | 元素很少 | 高级、聚焦 | 1 个主体 + 大留白 | 不是空 |
| 极繁 Maximal | 元素很多、很满 | 热闹、丰富 | 多图案 + 多颜色 | 容易乱 |

## 二、光线

| 术语 | 你在画面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 自然光 Natural Light | 阳光、窗光、阴天 | 真实、柔和 | 靠近窗户 / 黄金时刻 | 变化快 |
| 人造光 Artificial Light | 灯、闪光灯、LED | 可控、稳定 | 柔光箱 / 反光板 / 灯架 | 注意色温 |
| 硬光 Hard Light | 阴影边缘清晰 | 戏剧、强对比 | 小光源 / 裸灯 / 直射太阳 | 皮肤瑕疵明显 |
| 柔光 Soft Light | 阴影边缘柔和 | 温柔、自然 | 大柔光箱 / 柔光布 / 阴天 | 太柔会没立体 |
| 顺光 Front Light | 光从相机方向打来 | 明亮、平、少阴影 | 光源在机位后方 | 容易平 |
| 侧光 Side Light | 一半亮一半暗 | 立体、性格 | 光源 90° 侧 | 光比要控制 |
| 逆光 Backlight | 光从主体背后打来 | 轮廓、氛围、剪影 | 光源在主体后 | 注意曝光 |
| 侧逆光 Rembrandt / Rim | 侧后方来光 | 轮廓 + 立体 | 光源后侧 45° | 人像常用 |
| 顶光 Top Light | 头顶亮，眼窝暗 | 压迫、疲惫 | 光源正上方 | 人像慎用 |
| 底光 Underlight | 下巴亮，阴影反向 | 恐怖、怪诞 | 光源低于脸 | 常配暗背景 |
| 主光 Key Light | 最主要的光 | 定亮部和阴影 | 45° 侧前方 | 决定气氛 |
| 辅光 Fill Light | 阴影里的细节 | 降光比 | 反光板 / 柔光 | 太强会平 |
| 轮廓光 Rim Light | 主体边缘一圈亮 | 分离背景 | 逆光 / 侧逆光 | 太强像抠图 |
| 背景光 Background Light | 背景有亮斑 | 层次、氛围 | 打墙 / 打窗帘 | 和轮廓光不同 |
| 黄金时刻 Golden Hour | 日出后 / 日落前 1 小时 | 暖、柔、长影子 | 色温 3000–4500K | 时间短 |
| 蓝调时刻 Blue Hour | 日落后 / 日出前 20–40 分钟 | 冷、静、城市 | 色温 7000–10000K | 需要稳定 |
| 阴天散射光 Overcast | 没有硬阴影 | 柔和、均匀 | 云层当柔光罩 | 容易平 |
| 窗光 Window Light | 一侧亮，渐变到暗 | 自然、柔和 | 靠近窗户，白纱柔化 | 方向固定 |
| 伦勃朗光 Rembrandt | 颧骨下三角亮区 | 立体、古典 | 主光 45° 侧上 | 和蝴蝶光不同 |
| 蝴蝶光 Butterfly | 鼻子下蝴蝶阴影 | 美化、时尚 | 主光正前方偏上 | 适合正面 |
| 分割光 Split Light | 脸一半亮一半暗 | 戏剧、性格 | 光源 90° 侧 | 光比大 |
| 环形光 Loop Light | 鼻子下小阴影，略微偏侧 | 自然、通用 | 主光 30–45° 侧上 | 最常用人像光 |
| 高调 High-Key | 整体亮、阴影少 | 干净、轻松 | 白背景 + 多灯 + 低光比 | 不是过曝 |
| 低调 Low-Key | 整体暗、亮部集中 | 神秘、电影 | 黑背景 + 侧光 | 暗部要有细节 |
| 光比 Lighting Ratio | 亮暗差距 | 戏剧 / 温柔 | 1:2 柔，1:4 中，1:8 强 | 用测光表 |
| 眼神光 Catchlight | 眼睛里有小亮点 | 有神、活 | 光源在眼睛前方 | 太大像 LED |
| 剪影 Silhouette | 主体全黑，背景亮 | 神秘、形状 | 逆光 + 对背景曝光 | 轮廓要清楚 |
| 体积光 Volumetric | 光束可见 | 神圣、梦幻 | 逆光 + 烟雾 / 尘埃 | 需要介质 |
| 丁达尔 Tyndall | 树林 / 窗户光柱 | 自然、清晨 | 阳光 + 雾 / 灰尘 | 和体积光基本同义 |
| 反射 Reflection | 水面 / 玻璃 / 金属倒影 | 对称、空间 | 低角度 + 平静表面 | 注意虚实 |
| 折射 Refraction | 透过玻璃 / 水看到变形 | 梦幻、实验 | 玻璃 / 水 / 棱镜 | 控制畸变 |
| 透射 Transmission | 光穿过半透明材质 | 柔和、温暖 | 纸、布、磨砂玻璃 | 注意色偏 |
| 混合光 Mixed Lighting | 冷暖光同时存在 | 真实、城市、复杂 | 窗光 + 钨丝灯 / 霓虹 | 注意白平衡 |

## 三、色彩

| 术语 | 你在画面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 色相 Hue | 红橙黄绿青蓝紫 | 定颜色 | HSL 的 H | 和饱和度、明度分开 |
| 饱和度 Saturation | 鲜艳还是灰 | 情绪、风格 | HSL 的 S；-20% 到 +20% 常见 | 太高会溢出 |
| 明度 Lightness / Value | 亮还是暗 | 层次、轻重 | HSL 的 L；曲线 / 色阶 | 和曝光不同 |
| 冷暖 Warm / Cool | 偏黄橙 / 偏蓝青 | 情绪、时间 | 色温 ±300–800K | 和色调不同 |
| 互补色 Complementary | 色轮对面 | 张力、强调 | 蓝 / 橙，紫 / 黄 | 用量要控制 |
| 类似色 Analogous | 色轮相邻 | 和谐 | 蓝 / 青 / 绿 | 容易平 |
| 三角色 Triadic | 色轮三等分 | 活泼、平衡 | 红 / 黄 / 蓝 | 难控制 |
| 分裂互补 Split-Complementary | 一个主色 + 对面两侧 | 对比但柔和 | 蓝 + 橙黄 / 红橙 | 比互补好驾驭 |
| 单色 Monochromatic | 一个色相的不同明度 | 统一、极简 | 同一 H，变 S / L | 容易单调 |
| 双色 Duotone | 两个颜色映射明暗 | 海报、复古 | 高光一色，阴影一色 | 和渐变映射接近 |
| 三色 Tri-color | 三个主色 | 活泼、品牌 | 60-30-10 比例 | 不要平均分 |
| 色板 Palette | 一组固定颜色 | 统一 | 5–9 个颜色 | 越多越难统一 |
| 主色 / 辅色 / 点缀色 | 大面积 / 中面积 / 小面积 | 层级、品牌 | 60% / 30% / 10% | 点缀色最亮 |
| 60-30-10 法则 | 60% 主色，30% 辅色，10% 点缀 | 平衡 | 按面积分配 | 不是绝对 |
| 色彩对比 Color Contrast | 色相 / 明度 / 饱和度差异 | 强调、可读 | 互补 / 明暗 / 冷暖 | 太多会乱 |
| 同时对比 Simultaneous Contrast | 同一个颜色在不同背景上看起来不同 | 视觉错觉 | 背景影响前景 | 选色要看整体 |
| 色彩和谐 Color Harmony | 颜色放在一起舒服 | 统一 | 类似 / 互补 / 三角 | 不是所有和谐都好看 |
| 色调分离 Posterization | 颜色变成几档 | 复古、海报、故障 | 色阶 4–8 档 | 过度会脏 |
| 渐变 Gradient | 颜色过渡 | 氛围、科技 | 线性 / 径向 / 网格 | 不要太多 |
| 莫兰迪 Morandi | 灰调、低饱和 | 温柔、文艺 | 每色加灰，降饱和 | 和日系清透不同 |
| 马卡龙 Macaron | 粉彩、明亮、甜 | 少女、甜品、美妆 | 高明度 + 低饱和 | 容易甜腻 |
| 多巴胺 Dopamine | 高饱和、撞色 | 快乐、年轻 | 亮黄 / 粉 / 绿 | 容易刺眼 |
| 大地色 Earth Tones | 棕、米、橄榄、砖红 | 自然、复古、稳定 | 低饱和 + 暖色 | 容易闷 |
| 霓虹 Neon | 青、紫、粉的高亮 | 赛博、夜店 | 发光 + 深底 | 容易过曝 |
| 金属色 Metallic | 银、金、铬 | 奢华、科技、潮流 | 金属渐变 + 反射 | 容易俗 |
| 黑白 Black & White | 没有颜色，只有明暗 | 经典、纪实、情绪 | 去色 + 对比曲线 | 不是简单去色 |
| 青橙 Teal & Orange | 阴影青、肤色橙 | 电影、商业 | 阴影 +青，高光 +橙 | 过度像广告 |
| 胶片色 Film Color | 褪色、暖黄、绿青 | 复古、温度 | 胶片 LUT + 颗粒 | 不是真胶片 |
| 褪色 Faded | 像蒙了一层灰 | 复古、温柔 | 黑点上提，白点下压 | 过度会脏 |
| 高饱和 Saturated | 颜色很艳 | 活力、促销 | +20–40% | 容易溢出 |
| 低饱和 Desaturated | 颜色发灰 | 高级、冷静 | -20–50% | 太低没血色 |
| 暗调 Low-Key Color | 整体暗，亮部集中 | 神秘、电影 | 压暗背景，提亮主体 | 暗部要有细节 |
| 亮调 High-Key Color | 整体亮，阴影少 | 干净、轻松 | 白背景 + 低对比 | 不是过曝 |
| 色温 Temperature | 偏蓝 / 偏黄 | 冷暖、时间 | 3200K 暖，5600K 中性 | 和色调不同 |
| 色调 Tint | 偏绿 / 偏洋红 | 校正、风格 | 绿 / 洋红补偿 | 和色温不同轴 |
| 白平衡 White Balance | 白色是不是白 | 校正、统一 | 灰卡 / 手动 K | 风格化可故意偏 |
| LUT | 套上后整体变色 | 快速风格化 | 官方 / 第三方 LUT | 不同素材会翻车 |

## 四、材质与质感

| 术语 | 你在画面里看到什么 | 作用 | 复现参数 / 做法 | 易混 / 注意 |
| --- | --- | --- | --- | --- |
| 光滑 Smooth | 表面反光、无颗粒 | 现代、干净、贵 | 高光 + 反射 | 容易塑料 |
| 粗糙 Rough | 表面有颗粒 / 凹凸 | 自然、真实、手工 | 纹理 + 侧光 | 不要脏 |
| 哑光 Matte | 反光弱、柔和 | 高级、克制 | 低高光 + 柔光 | 和粗糙不同 |
| 光泽 Glossy | 强反光、亮 | 奢华、美妆、科技 | 高光 + 环境反射 | 容易过曝 |
| 金属 Metal | 银 / 金 / 铬的反光 | 科技、奢华、潮流 | 金属材质 + HDRI | 反射要匹配 |
| 玻璃 Glass | 透明、折射、反光 | 现代、通透 | 透射 + 折射 + 高光 | 注意背景 |
| 陶瓷 Ceramic | 温润、细腻、微反光 | 家居、茶、美妆 | 柔光 + 低反射 | 和塑料不同 |
| 布料 Fabric | 纹理、褶皱、柔软 | 生活、时尚 | 侧光 + 纹理 | 注意褶皱方向 |
| 纸张 Paper | 纤维、哑光、边缘 | 印刷、手工、复古 | 纸纹 + 柔光 | 和噪点不同 |
| 木材 Wood | 木纹、暖色、自然 | 家居、自然、复古 | 木纹 + 暖光 | 注意色差 |
| 石材 Stone | 颗粒、冷、重 | 建筑、自然、高级 | 侧光 + 纹理 | 容易脏 |
| 塑料 Plastic | 均匀、反光、轻 | 产品、玩具、廉价感 | 高光 + 纯色 | 容易假 |
| 皮革 Leather | 纹理、光泽、厚重 | 奢华、复古、时尚 | 侧光 + 纹理 | 注意反光 |
| 水 Water | 透明、反射、流动 | 清新、梦幻、自然 | 低角度 + 反光 | 注意快门 |
| 烟雾 Smoke | 半透明、流动 | 氛围、体积光 | 烟雾机 + 逆光 | 太多会脏 |
| 火焰 Fire | 暖色、跳动 | 危险、温暖、能量 | 实拍 / 素材 | 注意色温 |
| 尘埃 Dust | 小颗粒在光里 | 真实、怀旧 | 逆光 + 颗粒 | 不要太多 |
| 颗粒 Grain | 细密噪点 | 胶片、质感 | 5–15% | 和噪点接近 |
| 噪点 Noise | 随机彩色 / 亮度点 | 真实、故障 | 3–10% | 不要和颗粒混 |
| 纹理 Texture | 表面有可触摸的细节 | 真实、层次 | 纸张 / 布料 / 石材 | 和图案不同 |
| 笔触 Brushstroke | 可见的绘画笔触 | 手绘、艺术、表现 | 油画 / 水彩 / 数字笔刷 | 注意一致性 |
| 印刷网点 Halftone | 点阵表现明暗 | 印刷、波普 | 半调滤镜 | 和噪点不同 |
| 丝网印刷 Screen Print | 颜色少、套色偏移 | 海报、潮流、复古 | 2–4 色 + 错位 | 注意套色 |
| 烫金 Foil | 金属反光 | 奢华、包装 | 金箔 + 压印 | 成本高 |
| 压纹 Emboss | 凹凸 | 纸张、包装、质感 | 压印 + 侧光 | 需要工艺 |
| 浮雕 Relief | 凸起的形 | 古典、纪念、质感 | 3D / 雕刻 | 和压纹不同 |
| 3D 渲染 3D Render | 立体、材质、光 | 产品、科技、动画 | Blender / C4D / Spline | 注意塑料感 |
| 粘土 Clay | 圆润、软、手捏 | 亲和、儿童 | 粘土材质 + 柔光 | 和 3D 不同 |
| 毛毡 Felt | 纤维、软、温暖 | 手工、儿童、品牌 | 毛毡材质 + 柔光 | 注意绒毛 |
| 剪纸 Paper Cut | 多层纸、阴影 | 手工、儿童、动画 | 分层 + 投影 + 纸纹 | 和拼贴不同 |
| 拼贴 Collage | 不同图片 / 材质剪贴 | 潮流、杂志、艺术 | 剪贴 + 半调 + 手撕边 | 容易乱 |
| 故障 Glitch | 撕裂、色差、像素 | 赛博、前卫 | 故障素材 + 位移 | 不要滥用 |
| 扫描线 Scanlines | 横向细线 | 老电视、赛博 | 条纹 + 混合模式 | 注意摩尔纹 |
| 色差 Chromatic Aberration | 边缘红 / 蓝边 | 镜头感、复古 | 色差滤镜 | 太强像 3D 眼镜 |
| 模糊 Blur | 画面不清晰 | 梦幻、速度、隐私 | 高斯 / 动感 / 径向 | 和景深不同 |
| 景深 Depth of Field | 前后清晰范围 | 分离主体 | 大光圈 / 长焦 | 和后期模糊不同 |

## 五、字体排印

## 九、AI 图像痕迹

**先说明：以下只是线索，不是判决。** 看到两三条不要直接说「这是 AI」；看到多条再写「看起来像 AI 生成」，并给证据。

| 痕迹 | 你看到什么 | 为什么会这样 | 怎么确认 |
| --- | --- | --- | --- |
| 过度光滑 | 皮肤像塑料，没有毛孔 | 模型倾向平均化 | 放大看纹理 |
| 手部异常 | 手指数量 / 关节 / 握持不对 | 手部结构复杂 | 数手指、看关节 |
| 文字乱码 | 招牌 / 书页 / 屏幕文字不成词 | 模型不擅长精确文字 | 放大看字母 |
| 对称过度 | 脸 / 建筑 / 图案过于完美 | 模型倾向对称 | 找不对称细节 |
| 光影不一致 | 多个光源方向矛盾 | 生成时没有统一光照 | 看阴影方向 |
| 景深错误 | 前景虚、背景也虚，或边缘不自然 | 深度估计错误 | 看焦平面 |
| 材质重复 | 纹理像复制粘贴 | 模型重复模式 | 找重复图案 |
| 反射错误 | 镜面 / 水面反射与场景不符 | 反射关系复杂 | 看反射内容 |
| 物理错误 | 物体漂浮、穿插、比例不对 | 模型不懂物理 | 找接触点 |
| 过度锐化 | 边缘像刀切 | 后期 / 模型倾向 | 放大看边缘 |
| 噪点均匀 | 噪点像一层均匀膜 | 后期统一加 | 看暗部 / 亮部差异 |
| 构图太满 | 每个角落都有细节 | 模型倾向填满 | 看留白 |
| 风格混杂 | 同时有 3 种以上风格 | 提示词冲突 | 看一致性 |

**写法：**

> 「手部有 6 根手指、招牌文字不成词、左右光源方向矛盾——这三条同时出现，看起来像 AI 生成。但不能仅凭画风确认。」

## 十一、常见组合配方

### 1. 日系清透人像

- 曝光 +0.3 到 +0.7
- 对比 -10 到 -20
- 饱和 -10 到 -20
- 阴影偏青，高光偏暖
- 柔光 / 窗光，f/2–f/2.8
- 留白多，背景干净
- 颗粒 3–5%

### 2. 港风夜景人像

- 暖黄路灯 + 霓虹点缀
- 阴影偏绿青
- 对比 +10 到 +20
- 饱和 -5 到 +10
- 颗粒 8–15%
- 暗角 -15
- 近景 / 特写，浅景深

### 3. 电影感产品图

- 深色背景 + 侧逆光
- 主光柔光 + 轮廓光
- 青橙调色
- 微距 / 长焦，f/2.8–f/8
- 材质反射要干净
- 黑位略提，高光不溢出

### 4. 复古胶片

- 暖色 + 褪色
- 黑位 +10 到 +20
- 高光 -10 到 -20
- 颗粒 10–15%
- 光晕 / 色差轻微
- 暗角 -10 到 -20

### 5. 极简海报

- 1–2 色 + 大留白
- 1–2 种字体
- 大标题 + 小注释
- 网格对齐
- 一个视觉焦点
- 不要超过 3 个元素

### 6. 酸性潮流海报

- 荧光色 + 黑色
- 扭曲字 / 金属字
- 网格 / 噪点 / 半调
- 高对比
- 元素多但有主次
- 注意可读性

### 7. 小红书封面

- 3:4，1080×1440
- 大字 2–6 字一行
- 人物 / 产品占一半
- 高对比 / 高饱和
- 贴纸 / 箭头 / 手绘元素
- 上下留 10–15% 安全区

### 8. 公众号封面

- 2.35:1，900×383
- 大标题 + 品牌 / 人物
- 背景干净
- 标题对比强
- 缩略图能读
- 不要放小字
