# 风格与流派词典

用法：风格是坐标，不是判决。一件作品常常混了两三种风格，先找**主导特征**，再给名字。不要把「一个转场」「一个滤镜」说成一种风格。

每张卡给四件事：怎么认、常见载体、关键参数、容易和谁混。

---

## 一、平面 / 品牌 / UI 风格

### 01 极简主义 Minimalism

- **识别**：元素少、留白多、颜色少、字体克制、没有装饰性纹理。
- **常见载体**：品牌官网、SaaS、作品集、家居、包装。
- **关键参数**：1–2 个颜色，1–2 种字重，8pt 网格，区块间距 64–120px，圆角 0–12px。
- **易混**：极简不是「空」。它靠比例、对齐、材质和留白撑住，不是把内容删光。

### 02 瑞士国际主义 Swiss Style

- **识别**：严格网格、无衬线字体、左对齐、不对称、大字号、摄影优先。
- **常见载体**：编辑设计、品牌、海报、展览、企业报告。
- **关键参数**：Helvetica 类无衬线，12 栏网格，字号层级 3–5 级，留白大。
- **易混**：和极简接近。瑞士风格更强调网格和排版秩序，极简更强调元素数量少。

### 03 包豪斯 Bauhaus

- **识别**：几何形（圆、方、三角）、原色（红黄蓝）、功能主义、无装饰。
- **常见载体**：海报、品牌、教育、建筑、展览。
- **关键参数**：红黄蓝 + 黑 / 白，几何图形，无衬线，网格。
- **易混**：和孟菲斯都用几何和亮色。包豪斯更克制、更功能；孟菲斯更 playful、更多图案。

### 04 粗野主义 Brutalism

- **识别**：大黑字、原始 HTML 感、硬边、撞色、故意不精致。
- **常见载体**：文化机构、独立品牌、潮流网站、海报。
- **关键参数**：系统字体，黑 / 白 / 亮色，无圆角，1–4px 硬边，密集排版。
- **易混**：和「做得糙」不同。粗野主义是刻意选择，结构通常很清楚。

### 05 新粗野主义 Neubrutalism

- **识别**：粗黑边、硬阴影、亮色、贴纸感、圆角但仍然硬。
- **常见载体**：SaaS、创作者工具、潮流品牌、落地页。
- **关键参数**：3–4px 黑边，4–8px 硬阴影（无模糊），高饱和色，圆角 8–16px。
- **易混**：和粗野主义相比更规整、更商业、更适合 UI。

### 06 孟菲斯 Memphis

- **识别**：几何图形、撞色、波浪线、斑点、不对称、 playful。
- **常见载体**：潮流海报、包装、时尚、音乐、儿童。
- **关键参数**：3–5 个亮色，几何图案，粗线条，随机排列。
- **易混**：和包豪斯都用几何。孟菲斯更装饰、更不讲功能。

### 07 波普艺术 Pop Art

- **识别**：高饱和、粗描边、半调网点、漫画感、重复、消费符号。
- **常见载体**：海报、包装、潮流、音乐、广告。
- **关键参数**：原色 / 荧光色，2–4px 描边，半调网点，大字。
- **易混**：和孟菲斯都亮。波普更强调大众文化符号和印刷感。

### 08 构成主义 Constructivism

- **识别**：红黑、斜线、大字、拼贴、摄影蒙太奇、强方向。
- **常见载体**：海报、文化、政治宣传、展览。
- **关键参数**：红 / 黑 / 米白，斜构图，无衬线大字，几何线条。
- **易混**：和包豪斯都几何。构成主义更政治、更斜、更拼贴。

### 09 装饰艺术 Art Deco

- **识别**：金色、几何、对称、细线、奢华、向上放射。
- **常见载体**：酒店、珠宝、品牌、海报、建筑。
- **关键参数**：金 / 黑 / 墨绿，对称，细线，几何装饰，衬线或装饰字体。
- **易混**：和新艺术都装饰。Art Deco 更几何、更对称；新艺术更曲线、更植物。

### 10 新艺术 Art Nouveau

- **识别**：有机曲线、植物、花卉、手绘、装饰性边框。
- **常见载体**：品牌、包装、海报、婚礼、插画。
- **关键参数**：曲线，花卉，柔和色，衬线 / 手写字体。
- **易混**：和洛可可都曲线。新艺术更植物、更平面；洛可可更轻盈、更粉彩。

### 11 中世纪现代 Mid-Century Modern

- **识别**：暖木、几何、复古插画、低饱和、简洁但有温度。
- **常见载体**：家居、品牌、插画、包装、室内。
- **关键参数**：木色 / 芥末黄 / 墨绿，几何插画，无衬线，纹理。
- **易混**：和复古接近。Mid-Century 更具体地指向 1950–60 年代的家具 / 插画语言。

### 12 极繁主义 Maximalism

- **识别**：元素多、颜色多、图案叠、没有留白、视觉很满。
- **常见载体**：时尚、潮流、音乐、包装、杂志。
- **关键参数**：3–6 个颜色，多种图案，大字，叠层。
- **易混**：和拼贴接近。极繁是整体密度高；拼贴是不同材质剪贴。

### 13 侘寂 Wabi-Sabi

- **识别**：粗糙、自然、不对称、留白、旧物感、不完美。
- **常见载体**：家居、茶、陶艺、品牌、摄影。
- **关键参数**：大地色，粗糙纹理，自然光，不对称，留白。
- **易混**：和日式极简都留白。侘寂更粗、更旧、更不完美；日式极简更干净、更精确。

### 14 北欧风 Scandinavian

- **识别**：浅色、木色、留白、功能、柔和、自然。
- **常见载体**：家居、SaaS、品牌、包装。
- **关键参数**：白 / 浅灰 / 木色 / 少量绿，无衬线，圆角适中，留白多。
- **易混**：和日式极简接近。北欧更暖、更功能；日式更克制、更自然材质。

### 15 日式极简 Japanese Minimal

- **识别**：米白、原木、低饱和、细字、留白、自然材质。
- **常见载体**：家居、品牌、包装、餐饮、摄影。
- **关键参数**：米白 / 木 / 灰，细字重，留白 40–60%，自然光。
- **易混**：和侘寂、北欧都接近。日式极简更精确、更安静；侘寂更粗粝。

### 16 莫兰迪 Morandi

- **识别**：灰调、低饱和、柔和、颜色像蒙了一层灰。
- **常见载体**：家居、美妆、品牌、摄影、包装。
- **关键参数**：每个颜色加灰，饱和 -30% 到 -50%，低对比。
- **易混**：和日系清透不同。莫兰迪更灰、更闷；日系更亮、更青。

### 17 多巴胺 Dopamine

- **识别**：高饱和、撞色、快乐、圆润、图案多。
- **常见载体**：美妆、食品、潮流、社交、包装。
- **关键参数**：亮黄 / 粉 / 绿 / 蓝，饱和 +30%，大圆角，粗字。
- **易混**：和糖果色接近。多巴胺更撞色、更刺激；糖果色更粉彩、更甜。

### 18 玻璃拟态 Glassmorphism

- **识别**：半透明、背景模糊、细白边、浅色渐变、层次。
- **常见载体**：科技、金融、SaaS、品牌、概念 UI。
- **关键参数**：`backdrop-filter: blur(20px)`，白 10%，1px 白 20%，圆角 12–24px。
- **易混**：和新拟态都软。玻璃拟态是透明 + 模糊；新拟态是同色 + 双向阴影。

### 19 新拟态 Neumorphism

- **识别**：元素和背景同色，靠双向阴影凸起 / 凹陷，低对比。
- **常见载体**：智能家居、概念 UI、音乐播放器。
- **关键参数**：背景 #E0E5EC，亮阴影左上，暗阴影右下，圆角 16–24px。
- **易混**：和玻璃拟态不同。新拟态没有透明和模糊，对比度低，慎用于正文。

### 20 拟物化 Skeuomorphism

- **识别**：真实材质、皮革、金属、纸张、高光、纹理。
- **常见载体**：早期 iOS、游戏、品牌、节日活动页。
- **关键参数**：纹理 + 高光 + 投影 + 真实材质。
- **易混**：和新拟态不同。拟物化模仿真实物体；新拟态只模仿凸起 / 凹陷。

### 21 编辑式排版 Editorial

- **识别**：大标题、衬线字、分栏、图文混排、网格、留白。
- **常见载体**：媒体、品牌、博客、杂志、报告。
- **关键参数**：衬线标题 48–120px，正文 16–18px，12 栏，分栏 2–3。
- **易混**：和杂志风接近。编辑式更强调内容和网格；杂志风更强调封面和视觉冲击。

### 22 拼贴 Collage

- **识别**：不同图片 / 材质剪贴、手撕边、半调、错位、混合模式。
- **常见载体**：潮流、音乐、杂志、海报、MV。
- **关键参数**：剪贴 + 纸张纹理 + 半调 + 错位。
- **易混**：和极繁不同。拼贴强调材质和剪贴痕迹；极繁强调密度。

### 23 酸性设计 Acid Graphics

- **识别**：荧光色、扭曲字、金属、网格、噪点、未来感。
- **常见载体**：潮流、音乐、海报、时尚、club。
- **关键参数**：荧光绿 / 粉 / 紫，扭曲字体，金属渐变，网格 / 噪点。
- **易混**：和 Y2K 都金属 / 荧光。酸性更扭曲、更锐；Y2K 更银灰、更透明、更像素。

### 24 Y2K

- **识别**：银灰、亮面、透明、像素、荧光、未来复古。
- **常见载体**：潮流、美妆、音乐、时尚、包装。
- **关键参数**：银 / 白 / 荧光，金属高光，像素元素，透明塑料。
- **易混**：和蒸汽波不同。Y2K 更亮、更银、更未来；蒸汽波更粉紫、更复古。

### 25 蒸汽波 Vaporwave

- **识别**：粉紫、网格、罗马雕塑、日文、复古电脑、渐变。
- **常见载体**：音乐、潮流、视觉、MV。
- **关键参数**：粉 / 紫 / 青，网格，渐变，复古元素，低速。
- **易混**：和赛博朋克不同。蒸汽波更柔和、更怀旧；赛博更暗、更硬、更故障。

### 26 赛博朋克 Cyberpunk

- **识别**：霓虹、青紫、雨夜、故障、汉字 / 日文招牌、高对比。
- **常见载体**：游戏、科幻、音乐、电影、品牌。
- **关键参数**：深底 #0B0B12，霓虹青 / 紫 / 粉，故障，扫描线，雨。
- **易混**：和蒸汽波不同。赛博更暗、更危险、更叙事。

### 27 复古未来主义 Retro-Futurism

- **识别**：复古元素 + 未来科技，老式屏幕、金属、霓虹、太空。
- **常见载体**：游戏、品牌、音乐、海报。
- **关键参数**：金属 + 霓虹 + 老式 UI + 网格。
- **易混**：和赛博不同。复古未来更乐观、更复古；赛博更反乌托邦。

### 28 像素风 Pixel Art

- **识别**：像素块、硬边、低分辨率、有限色板。
- **常见载体**：游戏、复古、潮流、社交。
- **关键参数**：16–64 色，无抗锯齿，像素网格对齐。
- **易混**：和低画质不同。像素风是刻意控制像素；低画质是压缩失真。

### 29 低多边形 Low Poly

- **识别**：几何切面、少细节、平面着色、3D 感。
- **常见载体**：3D、游戏、科技、插画。
- **关键参数**：低面数，flat shading，统一色板。
- **易混**：和等距不同。低多边形是材质 / 面数；等距是视角。

### 30 等距 Isometric

- **识别**：2.5D 视角、无透视、30° 轴测、干净几何。
- **常见载体**：SaaS、科技、信息图、游戏。
- **关键参数**：30° 轴测，统一色板，无透视收缩。
- **易混**：和低多边形不同。等距是视角，低多边形是面数。

### 31 3D / 粘土 Claymorphism

- **识别**：立体、圆润、软、材质感、柔和光。
- **常见载体**：产品、科技、儿童、品牌、动画。
- **关键参数**：大圆角 + 内阴影 + 柔光 + 粘土 / 塑料材质。
- **易混**：和拟物化不同。粘土风更抽象、更圆；拟物化更真实。

### 32 剪纸 / 毛毡 Paper Cut / Felt

- **识别**：多层纸 / 毛毡、边缘阴影、手工感、柔软。
- **常见载体**：儿童、教育、动画、品牌、节日。
- **关键参数**：分层 + 投影 + 纸纹 / 绒毛 + 暖色。
- **易混**：和拼贴不同。剪纸 / 毛毡是单一材质的分层；拼贴是多种材质混合。

### 33 半调 / 丝网印刷 Halftone / Screen Print

- **识别**：网点、有限色、套色偏移、纸张纹理。
- **常见载体**：海报、包装、潮流、杂志。
- **关键参数**：2–4 色，半调网点，套色错位 1–3px，纸纹。
- **易混**：和波普接近。半调是印刷技术；波普是艺术运动。

### 34 故障艺术 Glitch Art

- **识别**：撕裂、色差、像素错位、扫描线、数据损坏。
- **常见载体**：音乐、潮流、赛博、MV、海报。
- **关键参数**：故障素材 + 位移 + 色差 + 扫描线。
- **易混**：和赛博不同。故障是效果；赛博是世界观。

### 35 电影感 Cinematic

- **识别**：宽画幅、浅景深、青橙、低调光、慢运镜、24fps。
- **常见载体**：广告、品牌片、预告、MV。
- **关键参数**：2.39:1，24fps，35–85mm，f/1.4–f/2.8，青橙，颗粒。
- **易混**：不是加黑边就叫电影感。它是画幅、镜头、光、色、节奏的组合。

### 36 纪录片感 Documentary

- **识别**：手持、自然光、同期声、长镜头、低饱和、少配乐。
- **常见载体**：人物故事、Vlog、调查、品牌纪实。
- **关键参数**：24–35mm，f/2.8–f/4，自然光，同期声，长镜头。
- **易混**：和「真实」不是一回事。纪录片感是一种拍法，不代表内容一定真实。

### 37 韦斯·安德森 Wes Anderson

- **识别**：对称、粉彩、正面机位、章节卡、横移、舞台感。
- **常见载体**：电影、广告、MV、品牌。
- **关键参数**：中心构图，粉彩，平视，横移 / 固定，衬线 + 无衬线。
- **易混**：不是所有对称都叫韦斯。还要有粉彩、舞台调度和冷幽默。

### 38 王家卫 Wong Kar-wai

- **识别**：霓虹、抽帧、手持、特写、独白、暖色、暧昧。
- **常见载体**：电影、MV、广告、时尚。
- **关键参数**：慢快门 + 抽帧，暖色霓虹，近景 / 特写，手持。
- **易混**：不是加个霓虹滤镜。抽帧、独白、空间遮挡都是语言的一部分。

### 39 新海诚 Makoto Shinkai

- **识别**：高光、云、天空、饱和、光晕、细节丰富、青春。
- **常见载体**：动画、MV、广告、游戏。
- **关键参数**：高光 + 光晕 + 蓝紫天空 + 高饱和 + 细节。
- **易混**：不是所有日系动画。新海诚更强调天空、光和环境细节。

### 40 吉卜力 Studio Ghibli

- **识别**：手绘、自然、柔光、生活细节、绿色、温暖。
- **常见载体**：动画、插画、品牌、广告。
- **关键参数**：手绘质感，绿色 / 暖色，柔光，生活化细节。
- **易混**：和「日系」不同。吉卜力更手绘、更自然、更生活。

### 41 3b1b 数学动画

- **识别**：深色背景、彩色线条、公式、逐步推导、旁白。
- **常见载体**：科普、数学、教育、知识视频。
- **关键参数**：近黑背景，高饱和线条（蓝 / 黄 / 红），公式逐步出现，2–4 秒一步。
- **易混**：和白板动画不同。3b1b 是数字动画 + 公式；白板是手绘 + 白底。

### 42 Vox 解释动画

- **识别**：拼贴、纸张、地图、图表、旁白、快节奏、信息密度高。
- **常见载体**：新闻、解释、科普、财经。
- **关键参数**：拼贴 + 图表 + 旁白 + 1–3 秒一个元素 + 来源上屏。
- **易混**：和动态图形不同。Vox 更强调新闻解释和信息证据。

### 43 白板动画 Whiteboard

- **识别**：白底、手绘线条、逐笔出现、旁白、轻音效。
- **常见载体**：教育、讲解、广告、企业培训。
- **关键参数**：白 / 浅灰底，手绘线条，逐笔，2–4 秒一个元素。
- **易混**：和 3b1b 不同。白板是手绘 + 白底；3b1b 是数字线条 + 深底。

### 44 动态图形 Motion Graphics

- **识别**：几何、文字、图形运动、关键帧、品牌系统。
- **常见载体**：片头、品牌、信息图、广告、UI 动效。
- **关键参数**：关键帧 + 缓动 + 图形系统 + 节奏。
- **易混**：和实拍特效不同。动态图形通常是 2D / 2.5D 图形动画。

### 45 定格 / 粘土动画 Stop Motion / Claymation

- **识别**：逐帧移动、手工质感、指纹 / 布纹、轻微抖动。
- **常见载体**：广告、动画、MV、儿童。
- **关键参数**：12–24fps，逐帧拍，粘土 / 布偶，柔光。
- **易混**：和低帧率视频不同。定格是逐帧实物拍摄；低帧率是视频抽帧。

## 二、怎么判断「这是不是某某风格」

1. **先找 3 个以上特征**，不要凭一个元素下结论。
2. **看它是否贯穿全片 / 全页**。只出现在一个镜头里，那是技巧，不是风格。
3. **看它是否稳定**。换一个页面 / 镜头还在，才是风格。
4. **看它是否有意为之**。同样的效果可能是平台压缩、模板、AI 默认，不一定是风格。
5. **给「主导 + 次要」**。例：「主导是瑞士风格，次要有一点新粗野主义的硬边。」
